# Расписание 1 «Д» класса

Школа-лицей № 37 имени Сырбая Мауленова. Кабинет 232.
Разработчик: Руслан Закирович.

Сайт: https://mg-trener.github.io/ruslan/

Статический сайт на HTML, CSS и JavaScript по образцу MG-Trener/Zakir, Artur и alisa: неоновая неделя, выбор дня, подсветка текущего урока по времени Астаны, таймер перемен, напоминание за минуту до звонка и сезонные карточки каникул.

Расписание перенесено с предоставленного изображения: 20 занятий, по 4 каждый будний день с 08:00 до 11:05. Перемены: 5, 15 и 5 минут. Кабинет 232 указан на изображении.

## Изменение данных

- `script.js`: звонки (`periods`), предметы и кабинет (`days`), короткие названия для телефона (`shortNames`).
- `index.html`: школа, класс и подпись разработчика.
- `holiday-widget.js`: календарь каникул 2026/27, включая дополнительные каникулы первого класса 8–14 февраля 2027 года, возвращение 15 февраля. Календарь обновляется отдельно на следующий учебный год.
- Источник календаря: https://www.gov.kz/memleket/entities/edu/press/news/details/1266458?lang=ru

## Проверка

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

```sh
node --check script.js
node --check holiday-widget.js
node tests/holidays.cjs
```

GitHub Pages публикует корень ветки `main`.
